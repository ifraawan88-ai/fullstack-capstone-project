# GiftLink User Stories

## User Story Template

**As a** [type of user]
**I want** [some goal]
**So that** [some reason/benefit]

### Acceptance Criteria

* [ ] The user can perform the requested action.
* [ ] The system validates the required information.
* [ ] The system displays an appropriate success or error message.
* [ ] The feature works correctly for the intended user.

## Example User Story

**As a** registered user
**I want** to list a household item that I no longer need
**So that** another user can find and receive it for free.

### Acceptance Criteria

* [ ] User must be logged in to create a listing.
* [ ] User can enter the item's title, description, category, and other required details.
* [ ] The item is saved in the database.
* [ ] The newly added item appears in the available items list.
